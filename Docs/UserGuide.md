# ClipStack 使用指南

免费、开源、本地的 macOS 剪贴板管理器。应用运行在菜单栏，自动记录复制过的内容，数据只保存在本机。

应用内也可通过 **帮助 → ClipStack 帮助** 打开同一套说明（支持帮助菜单顶部的搜索框）。

## 快速开始

1. 从 [Releases](https://github.com/SkyierSeven/ClipStack/releases) 安装 `ClipStack.app`
2. 在菜单栏找到剪贴板图标
3. 使用默认快捷键 `⌘⇧X` 打开历史面板（可在设置中修改）
4. 复制内容后，卡片会出现在面板中；**点击卡片即可复制**

### 辅助功能权限

右键菜单中的「插入到当前应用」需要辅助功能权限：

**系统设置 → 隐私与安全性 → 辅助功能** → 勾选 ClipStack。

重新编译或替换 App 后，macOS 可能要求重新勾选。

## 历史面板

| 操作 | 说明 |
|------|------|
| 点击卡片 | 复制到系统剪贴板 |
| 滑入后空格 | Quick Look 预览 |
| `←` `→` | 切换卡片 |
| `Enter` | 复制选中项 |
| `Delete` | 删除选中项 |
| `Esc` | 关闭面板 |

### 固定

鼠标移到卡片上点图钉，或右键 →「固定」。固定项排在列表前面，不会被「清空历史」删掉，也不受历史上限裁剪。

### 分类

面板上方可按全部 / 文字 / 链接 / 图片 / 文件筛选。

## 搜索

顶部搜索框支持关键词（含图片 OCR 文字），以及过滤语法：

| 语法 | 作用 | 示例 |
|------|------|------|
| `type:` / `类型:` | 按类型 | `type:image` |
| `app:` / `应用:` | 按来源应用 | `app:Safari` |
| `pin:` / `固定:` | 只看固定项 | `pin:` |

可组合：`type:text app:Xcode 报错`

## 设置

菜单栏图标 → **设置…**

- **通用**：暂停记录、登录启动、复制后隐藏面板、历史上限
- **隐私**：排除不想被记录的应用
- **快捷键**：自定义呼出面板的全局快捷键

打开设置时，左上角菜单为：**暂停 / 打开面板 / 退出**，以及 **帮助**（含系统搜索框）。

## 隐私与数据

数据不会上传云端：

| 路径 | 内容 |
|------|------|
| `~/Library/Application Support/ClipStack/clipboard-data.json` | 元数据 |
| `~/Library/Application Support/ClipStack/images/` | 图片文件 |

## 常见问题

**打不开 App**  
右键打开，或在「隐私与安全性」中放行；也可 `xattr -cr /Applications/ClipStack.app`。

**插入没反应**  
检查辅助功能权限；替换 App 后删除旧条目再勾选；确保光标已在目标输入框。

**没有新历史**  
是否暂停了记录、来源应用是否在排除列表中。

更多反馈：[GitHub Issues](https://github.com/SkyierSeven/ClipStack/issues)
