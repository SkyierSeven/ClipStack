# ClipStack 使用指南

免费、开源、本地的 macOS 剪贴板管理器。

- 运行在**菜单栏**（日常不占 Dock）
- 自动记录文本、链接、图片、文件
- 支持搜索、固定、快捷键、排除应用
- **数据只保存在本机**，不会上传云端

应用内打开同一套说明：**打开设置 → 帮助 → ClipStack 帮助**（菜单顶部有系统搜索框）。

## 安装

1. 打开 [GitHub Releases](https://github.com/SkyierSeven/ClipStack/releases)
2. 下载 `ClipStack-*-macOS-arm64.zip` 或 `.dmg`
3. 将 `ClipStack.app` 拖入「应用程序」

### 提示「无法打开」时

任选一种方式：

1. **右键打开**：在 `ClipStack.app` 上右键 →「打开」→ 再点「打开」
2. **系统设置**：「系统设置 → 隐私与安全性」→「仍要打开」
3. **终端**：

```bash
xattr -cr /Applications/ClipStack.app
open /Applications/ClipStack.app
```

## 第一次使用

1. 启动后，在**菜单栏**找到剪贴板图标（没有 Dock 图标是正常的）
2. 首次启动会有简短引导：辅助功能、快捷键、登录时启动
3. 按默认快捷键 <kbd>⌘⇧X</kbd> 打开历史面板
4. 随便复制几段文字 / 截图，面板里会出现对应卡片
5. **点击卡片** → 内容写回系统剪贴板（可再粘贴到别处）

### 辅助功能权限（可选但推荐）

只有用到右键「插入到当前应用 / 纯文本插入」时才需要：

**系统设置 → 隐私与安全性 → 辅助功能** → 勾选 **ClipStack**

注意：自己重新编译或替换 App 后，macOS 常会要求你**删掉旧条目再重新勾选**一次。

## 历史面板

用快捷键或菜单栏「打开历史面板」呼出。

### 基本操作

| 操作 | 说明 |
|------|------|
| 点击卡片 | 复制到系统剪贴板 |
| 滑入后按 <kbd>空格</kbd> | Quick Look 快速查看 |
| <kbd>←</kbd> <kbd>→</kbd> | 在卡片间切换 |
| <kbd>Enter</kbd> | 复制当前选中项 |
| <kbd>Delete</kbd> | 删除当前选中项 |
| <kbd>Esc</kbd> | 关闭面板 |
| 清空历史 | 面板右上角「清空历史」（**不会**删固定项） |

点击复制后，默认会短暂提示「已复制到剪贴板」，并可在设置里选择是否自动收起面板。

### 固定

把常用内容钉在列表最前面：

- 鼠标移到卡片上 → 点右上角图钉  
- 或右键 →「固定」

固定项的特点：

- 排在未固定内容前面
- 「清空历史」不会删掉它们
- 不受「历史上限」裁剪

固定卡片**不会**做悬停放大，边框为琥珀色，方便和普通卡片区分。

### 分类筛选

面板上方可按：**全部 / 文字 / 链接 / 图片 / 文件** 过滤。

### 右键菜单

| 项目 | 说明 |
|------|------|
| 复制到剪贴板 | 与单击相同 |
| 插入到当前应用 | 模拟粘贴到先前焦点窗口（需辅助功能） |
| 快速查看 | 同空格预览 |
| 固定 / 取消固定 | 钉住或取消 |
| 纯文本插入 | 去掉富文本格式后插入 |
| 删除 | 从历史中移除 |

左侧「操作提示」卡片会常驻显示常用操作，本身不是一条剪贴板记录。

## 搜索

在面板顶部搜索框输入关键词即可。支持：

- 文本内容
- 来源应用名
- 图片经 OCR 识别出的文字（若有）

### 过滤语法

| 写法 | 作用 | 示例 |
|------|------|------|
| `type:` / `类型:` | 按类型 | `type:image`、`类型:链接` |
| `app:` / `应用:` | 按来源应用 | `app:Safari`、`应用:Xcode` |
| `pin:` / `固定:` / `pinned:` | 只看已固定 | `pin:` |

类型可用值：`text`/`文字`、`url`/`链接`、`image`/`图片`、`file`/`文件`（也支持 `txt`、`link`、`img` 等别名）。

可组合，例如：

```text
type:text app:Xcode 报错
类型:图片 pin:
```

搜索时会显示「全库搜索」与结果数量；点搜索框旁的 ✕ 可清空。

## 设置

菜单栏图标 → **设置…**

打开设置时，ClipStack 会暂时出现在 Dock，并显示左上角菜单，方便你发现窗口。

### 通用

| 选项 | 说明 |
|------|------|
| 暂停记录剪贴板 | 临时不再写入新历史 |
| 登录时启动 | 开机后自动在菜单栏运行 |
| 复制后隐藏面板 | 点击卡片复制后先提示，再自动收起 |
| 无限保留历史 | 关闭后可设置条数上限（仅约束**未固定**条目） |

### 隐私

添加「排除应用」：来自这些应用的复制**不会被记录**（适合密码管理器等）。没有默认黑名单。

### 快捷键

自定义「打开 / 关闭历史面板」的全局快捷键。修改后立即生效；若与其他软件冲突，请更换组合。

## 菜单栏与左上角菜单

### 菜单栏图标菜单

- 打开历史面板
- 暂停 / 恢复记录
- 设置…
- 退出

### 打开设置后的左上角菜单

| 菜单 | 内容 |
|------|------|
| **ClipStack** | 暂停 / 恢复、打开面板、退出 |
| **帮助** | 顶部**搜索框**、ClipStack 帮助、快捷键一览、在线文档、反馈问题 |

帮助搜索框是系统标准能力（与「文本编辑」等 App 相同）：输入「固定」「搜索」「权限」等可快速定位帮助条目。

## 隐私与数据

ClipStack **不会**把剪贴板内容上传到任何服务器。

| 路径 | 内容 |
|------|------|
| `~/Library/Application Support/ClipStack/clipboard-data.json` | 历史元数据、设置等 |
| `~/Library/Application Support/ClipStack/images/` | 图片文件 |

卸载时如需清除数据，可手动删除上述目录。

应用写入剪贴板（例如你从历史里再复制）时，不会再记成一条新历史，避免重复刷屏。

## 常见问题

### 打不开 / 提示身份不明的开发者

见上文[安装](#安装)中的三种放行方式。

### 菜单栏找不到图标

确认 App 已在运行；若在「暂停」或被菜单栏挤到「<<」折叠里，点折叠箭头查看。

### 设置窗口看不见

打开设置后看 Dock 是否出现 ClipStack；用左上角 **ClipStack → 打开面板** 或再次点菜单栏「设置…」。全屏空间有时会挡住普通窗口，切回桌面空间再看。

### 插入到当前应用没反应

1. 辅助功能里是否勾选了**当前这份** ClipStack  
2. 换过编译版本后：删掉旧条目 → 重新添加并勾选  
3. 插入前先把光标放在目标 App 的输入框里  

日常「点卡片复制 → 自己 ⌘V」不需要辅助功能权限。

### 历史里没有刚复制的内容

- 「暂停记录」是否开启  
- 来源应用是否在「排除应用」中  
- 是否其实是 ClipStack 自己写回剪贴板（不会重复入库）

### 图片搜不到字

OCR 依赖系统能力，复杂图或扫描件可能识别不出；纯截图文字一般更准。
