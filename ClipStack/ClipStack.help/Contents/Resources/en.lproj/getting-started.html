快速开始

ClipStack 是什么

菜单栏剪贴板历史工具：自动记录文本、链接、图片、文件，支持搜索与固定。默认没有 Dock 图标；打开「设置」时会短暂出现在 Dock。

安装

  1. 从 GitHub Releases 下载 zip 或 dmg
  2. 把 ClipStack.app 拖进「应用程序」
  3. 若无法打开：右键 →「打开」，或在「隐私与安全性」中放行，或执行 xattr -cr /Applications/ClipStack.app

第一次启动

  1. 在菜单栏找到剪贴板图标
  2. 按 ⌘⇧X 打开历史面板（可在设置中修改）
  3. 复制一些内容，卡片会出现在面板里
  4. 点击卡片即可写回系统剪贴板，然后到任意 App 里粘贴

辅助功能权限

仅「插入到当前应用 / 纯文本插入」需要。路径：

「系统设置 → 隐私与安全性 → 辅助功能」→ 勾选 ClipStack。

重新编译或替换 App 后，请删除旧条目再重新勾选。
